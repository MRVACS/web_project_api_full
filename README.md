# Tripleten web_project_api_full

Este proyecto consiste en una página web, estilo "red social" para viajeros. Utiliza CSS, HTML, Javascript, React, Vite, React Router y extensiones como Node.js para construir la interfaz (frontend), la cual incluye componentes que permiten Registrarse, Logearse y ver el perfil, allí se pueden apreciar las publicaciones (fotos de lugares) y se tiene la posibilidad de dar like.

También busca evidenciar los conocimientos en Express.js, representa el inicio de la creación de un servidor con información de usuarios y tarjetas asociadas a ellos. Además incorpora la utilización de base de datos (MongoDB y mongoose) para almacenar la información de los usuarios y tarjetas. Adicionalmente incorpora la funcionalidad de registro de usuarios e inicio de sesión, la cual cuenta con encriptación de contraseñas, autenticación de usuarios y rutas protegidas.
