Web Project Around Auth

Este proyecto consiste en una página web, estilo "red social" para viajeros. Utiliza CSS, HTML, Javascript, React, Vite, React Router y extensiones como Node.js para construir la interfaz (frontend), la cual incluye componentes que permiten Registrarse, Logearse y ver el perfil, allí se pueden apreciar las publicaciones (fotos de lugares) y se tiene la posibilidad de dar like.
